## Hotkeys

There's a ton of hotkeys documented for each tool so read the wiki carefully, but here are some that might be not:
- **Ctrl+Alt+W (Ctrl+Option+W for Mac):** Opens **Parent Component Editor**.
- **Ctrl+Alt+Q (Ctrl+Option+Q for Mac):** Opens **Parent Parameters**.
- **Ctrl+Shift+W (Mac: Option+Shift+W):** Opens **Selected COMP's Editor**.
- **Ctrl+Shift+Q (Mac: Option+Shift+Q):** Opens **Selected COMP's Parameters**.
- **Ctrl+Shift+F (Mac: Cmd+Shift+F):** Palette Search
- **Ctrl+0 (Mac: Cmd+0)**: Pulses [Global ResetPLS](/docs/resetpls1/#global-resetpls)

## TD_SearchPalette

An awesome UI mod by [Yea Chen](https://github.com/yeataro/TD-SearchPalette) which adds a search bar to the Palette browser. I have added the hotkey `ctrl+shift+F` to focus the search bar and type right away.
