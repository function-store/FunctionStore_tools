## Perform Window Tools

Drag and drop an operator to set it as the `Window Operator` of the `/perform` Window. **Left-Click** to open the viewer, **Right-Click** to configure. In the configuration popup you have the option to turn NDI/Spout streaming of the same window on/off also.

> Note: In case you want to change the perform window reference, do it so in the custom parameter of `/FunctionStore_tools/MY_TOOLBAR/containers/button_perform` and re-install the toolbar by pulsing the `Install` parameter of the `FNS_Toolbar` component.
