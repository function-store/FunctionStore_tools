Tabs

Settings, Install & remove and Updates are the console's own and always shown. Tools contribute the rest; hide any you do not want on the bar — the choice is written back to the tool and follows it.

Switch config scope to global?

Global scope roams settings through the machine-wide config file. Choose what happens right now: Push overwrites the global config with this project's current settings; Adopt applies the existing global config onto this project.

Update

Settings are snapshotted before anything is replaced and re-apply afterwards; a package the user never installed stays uninstalled.
