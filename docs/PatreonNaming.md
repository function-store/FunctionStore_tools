# Patreon, not Plus

"Plus" was the name for the packages the gate serves only to an entitled
account. Readers could not tell what it meant: a product tier, a paid
edition, a membership? The route in is a Patreon membership (or a Gumroad
key), so the marker says that.

## Decisions

- **Marker text is `Patreon:<tier>`**, the lowest tier that unlocks the
  tool: `Patreon:Base`, `Patreon:Pro`, `Patreon:Coaching`. Picker chip,
  questionnaire chip, landing-page row, docs sidebar and index, docs
  badge. Signed in, the chip reads `Patreon:Base · unlocked` or
  `Patreon:Base · locked`. A tier the manifest's ladder does not name
  falls back to plain `Patreon`.
  (Corrected 2026-09-13: the first pass shipped plain `Patreon` with the
  tier only in tooltips; the owner asked for the tier in the marker.)
- **The minimum tier is also spelled out** in the chip's tooltip, the
  docs page callout and the per-package list on `/patreon/`. It comes from
  the manifest's `toolkit.tiers` ladder (Base, Pro, Coaching), never a
  hand-typed copy. "Base tier or higher", because the ladder grants
  upward.
- **Gumroad is named wherever a licence key is**: "a Gumroad licence
  key". A package-specific "or a Gumroad key" only appears when the
  manifest says `key_available` (none today; the Worker's
  `GUMROAD_PRODUCTS` map is empty).
- **`/plus/` becomes `/patreon/`**, with a permanent redirect in
  `website/vercel.json`. Installed pickers link `FNS_DOCS + '/plus/'`, so
  the redirect is not optional.
- **The site nav had both `Plus` (internal) and `Patreon` (external).**
  They collapse into one `Patreon` link to `/patreon/`, which carries the
  Patreon buttons itself.

## Out of scope, on purpose

- **Storage and gate paths** (`fnstools/plus/` in R2, the Worker route,
  `upload.py`). A reader never sees them, and moving them breaks every
  published manifest's artifact URL.
- **Code identifiers and comments** (`isPlus`, `.plus-mark`,
  `.tier--plus`, `PLUSPKGS`). Renaming is churn with no reader.
- **History**: `packaging/CHANGELOG.md`, published manifests' `notes`,
  and the design docs in `docs/` that used the word at the time.
